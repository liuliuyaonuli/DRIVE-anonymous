# Anonymous Research Release

This repository is prepared for double-blind research review.

- Git history from the development repository is intentionally omitted.
- Personal usernames, local paths, credentials, logs, and private experiment artifacts are excluded.
- The release preserves the source code, public documentation, licenses, and reproducibility interfaces needed to inspect the method.
- Third-party attribution and license notices are retained.

The GitHub hosting account may still be visible because public GitHub repositories are owned by an account. This file contains no author identity or affiliation.
